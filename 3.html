Консультация 3. Операторы и выражения

Арифметика, сравнения, логика, побитовые операторы, приоритет, тернарный оператор и работа со строками

Цели консультации

К концу занятия слушатель должен:

  • Пониматьчто такое выражение и оператор, чем они отличаются
  • Уметьуверенно пользоваться арифметическими, сравнительными, логическими и побитовыми операторами
  • Знатьприоритет операторов и уметь расставлять скобки
  • Пониматьпрефиксный и постфиксный инкремент/декремент
  • Уметьприменять тернарный оператор
  • Уметьсобирать строки конкатенацией и интерполяцией

1. Выражение и оператор

Выражение — конструкция, которая вычисляется в значение: 2 + 3, x * y, name.Length. У выражения есть результат и тип.

Оператор (инструкция, statement) — законченное действие, обычно завершается ;: int x = 5;, Console.WriteLine(x);. Выражение может быть частью оператора.

Ключевая мысль занятия: операторы работают с операндами и возвращают результат определённого типа — и этот тип важно понимать, чтобы не ловить сюрпризы вроде 5 / 2 == 2.

2. Арифметические операторы

  • +сложение — a + b
  • -вычитание — a - b
  • *умножение — a * b
  • /деление — a / b
  • %остаток от деления — a % b
  • ++инкремент — a++, ++a
  • --декремент — a--, --a
Главная ловушка — деление целых. Если оба операнда целые, результат тоже целый, дробная часть отбрасывается.
Console.WriteLine(5 / 2); // 2 Console.WriteLine(5 / 2.0); // 2.5 Console.WriteLine(5 % 2); // 1

Чтобы получить дробный результат, хотя бы один операнд должен быть дробным (или нужен явный привод).

Остаток % полезен для проверки чётности (x % 2 == 0) и цикличности (индексы, «каждый N-й»).

Деление на ноль: для целых — исключение DivideByZeroException; для double/decimal — double даёт Infinity/NaN, decimal бросает исключение. Это стоит проговорить, чтобы не было сюрпризов.

Инкремент/декремент — префиксный и постфиксный

int a = 5; Console.WriteLine(a++); // 5, затем a = 6 (постфиксный: сначала значение, потом увеличение) Console.WriteLine(++a); // 7 (префиксный: сначала увеличение, потом значение)

На занятии — обязательно показать на доске/в отладчике, потому что это классический источник ошибок.

3. Операторы присваивания

Базовый = и составные:

int x = 10; x += 5; // x = x + 5 → 15 x -= 3; // 12 x *= 2; // 24 x /= 4; // 6 x %= 4; // 2

Составные операторы работают и с другими типами: += для строк — конкатенация (s += "!").

Отдельно упомянуть: x = y = z = 0 работает (присваивание возвращает значение), но читаемость страдает — лучше не злоупотреблять.

4. Операторы сравнения

Возвращают bool:

a == b // равно a != b // не равно a > b // больше a < b // меньше a >= b // больше или равно a <= b // меньше или равно
Важно: = — присваивание, == — сравнение. Компилятор поймает часть ошибок (if (x = 5) для int — ошибка), но для bool — нет, поэтому внимательность нужна.

Сравнение ссылочных типов (string, массивы) — это отдельная тема: == для string сравнивает содержимое (перегружен), а для массивов — ссылки. На базовом уровне достаточно: для строк == работает «как ожидается», для остальных ссылочных — пока не углубляемся.

5. Логические операторы

  • &&И (логическое) — a > 0 && b > 0
  • ||ИЛИ — a > 0 || b > 0
  • !НЕ — !flag
  • ^исключающее ИЛИ — a ^ b (для bool)
Ключевое понятие — сокращённое вычисление (short-circuit):
if (list != null && list.Count > 0) { ... } // если list == null, вторая часть не вычисляется

Это не просто оптимизация — это защита от NullReferenceException. Обязательно проговорить.

Разница &/&& и |/||: одиночные не сокращают вычисления и применимы к целым (побитово). На базовом уровне: для логики всегда &&/||, если нет особой причины.

6. Побитовые операторы

Кратко, но показать — полезно для понимания флагов и enum:

int a = 5; // 0101 int b = 3; // 0011 a & b // 0001 = 1 a | b // 0111 = 7 a ^ b // 0110 = 6 ~a // побитовое НЕ a << 1 // сдвиг влево: 1010 = 10 a >> 1 // сдвиг вправо: 0010 = 2

Не углубляться: цель — узнать, что они есть, и понимать << 1 как умножение на 2.

7. Приоритет операторов

Порядок (упрощённо, от высшего к низшему):

  • ()скобки
  • ++, --(постфиксные), !, унарный -
  • *, /, %умножение, деление, остаток
  • +, -сложение, вычитание
  • <<, >>сдвиги
  • <, >, <=, >=сравнения
  • ==, !=равенство
  • &, ^, |побитовые
  • &&, ||логические
  • ?:тернарный
  • =и составные присваивания
Практическое правило: если сомневаетесь — ставьте скобки. Это не признак слабости, а признак читаемого кода.

Пример-ловушка:

bool result = a > 0 && b > 0 || c > 0; // читается как: (a > 0 && b > 0) || (c > 0)

8. Тернарный оператор

условие ? значениеЕслиTrue : значениеЕслиFalse
int age = 20; string status = age >= 18 ? "взрослый" : "несовершеннолетний";
Правила: обе ветви должны давать совместимые типы; вложенные тернарники допустимы, но быстро теряют читаемость — лучше if/else, если больше двух вариантов.

9. Работа со строками

Конкатенация +

string name = "Анна"; int age = 25; Console.WriteLine("Имя: " + name + ", возраст: " + age);

Работает, но громоздко и легко ошибиться с пробелами; плюс неявно вызывает ToString().

Интерполяция $"..." — современный и предпочтительный способ

Console.WriteLine($"Имя: {name}, возраст: {age}"); Console.WriteLine($"Через год: {age + 1}");

Внутри {} можно писать выражения и форматирование: {age:D3}, {price:F2}, {date:dd.MM.yyyy}. Это стоит показать — сразу пригодится в задачах.

string.Format и + — упомянуть как альтернативы, но рекомендовать интерполяцию.

Важно: string неизменяемый, поэтому конкатенация в цикле — плохая идея (много промежуточных строк); для этого есть StringBuilder (подробнее — на теме строк).

10. Практические задания

  • 2Проверить, является ли число чётным (%), и вывести результат через тернарный оператор.
  • 3Показать разницу a++ и ++a на примере с выводом до/после.
  • 4Написать условие «число в диапазоне от 1 до 100 включительно» через && и проверить на разных значениях.
  • 5Продемонстрировать short-circuit: if (s != null && s.Length > 0) и объяснить, почему без && упадёт.
  • 6Собрать строку с именем, возрастом и городом через конкатенацию и через интерполяцию; сравнить читаемость.
  • 7Вывести стоимость товара с форматированием {price:F2} (два знака после запятой).

11. Типичные ошибки и вопросы новичков

  • 5 / 2 == 2забыли про целочисленное деление.
  • = вместо ==в условиях — особенно для bool.
  • a++ и ++aпутаница — разбираем на конкретных примерах.
  • &/| вместо &&/||нет короткого замыкания, возможен NullReferenceException.
  • Забытые скобкив составных условиях — a || b && c читается не так, как кажется.
  • + со строками и числами"1" + 2 даёт "12", а не 3; и наоборот, 1 + 2 + "3" даёт "33" (слева направо).
  • double и равенство0.1 + 0.2 == 0.3 даёт false; сравнивать с допуском.
  • Тернарник для побочных эффектовон для значений, а не для действий.
  • Приоритет % и *равны, выполняются слева направо.
