Консультация 10. Генерация случайных чисел в C#

Псевдослучайные числа, Random и Random.Shared, seed, диапазоны, выбор элемента и перемешивание

Примечание: в исходном плане тема 10 была «Обработка исключений и отладка». По вашему запросу заменяю её на тему про рандом. Если нужно — верну исключения отдельной консультацией.

Цели консультации

К концу занятия слушатель должен:

  • Пониматьчто такое псевдослучайные числа и почему они «псевдо»
  • Уметьпользоваться Random и Random.Shared для генерации чисел в диапазоне
  • Знатьразницу между Next(), Next(max), Next(min, max) и почему верхняя граница не включается
  • Уметьгенерировать дробные числа, случайные элементы массива/списка, перемешивать коллекцию
  • Пониматьроль seed и воспроизводимость
  • Знатьтипичные ошибки: создание Random в цикле, неверные границы, Random и многопоточность

1. Что такое псевдослучайные числа

Компьютер не умеет «бросать кубик» по-настоящему: он вычисляет последовательность чисел по алгоритму от начального значения — seed (зерно). Поэтому числа называются псевдослучайными: они выглядят случайными, но при одном и том же seed последовательность воспроизводима.

Практические следствия:

  • Seed явноесли задать seed явно — можно повторять сценарии (удобно для тестов и отладки)
  • Без seedберётся значение на основе времени/энтропии, и последовательность каждый запуск разная
  • Криптографиядля криптографии обычный Random не подходит — нужен RandomNumberGenerator (упомянуть, не углубляться)

2. Класс Random: базовое использование

var rnd = new Random(); int a = rnd.Next(); // 0 .. int.MaxValue-1 int b = rnd.Next(10); // 0 .. 9 (10 НЕ включается!) int c = rnd.Next(1, 7); // 1 .. 6 — как кубик double d = rnd.NextDouble(); // 0.0 .. 1.0 (1.0 не включается)
Ключевое правило, которое надо проговорить несколько раз: верхняя граница не включается.

Next(10) → 0…9;
Next(1, 7) → 1…6;
чтобы получить «от 1 до 10 включительно» — Next(1, 11).

Это самая частая ошибка новичков («выпадает только до 9, а надо до 10»). Лучше показать на конкретном «кубике»: Next(1, 7) — правильно, Next(1, 6) — нет.

3. Random.Shared — современный способ

Начиная с .NET 6 есть готовый общий экземпляр:

int n = Random.Shared.Next(1, 101); // 1..100 double d = Random.Shared.NextDouble();

Плюсы:

  • Без объектане нужно создавать свой объект
  • Потокобезопасен(можно использовать из разных потоков)
  • Seedвнутри использует хороший seed
Рекомендация для занятий: в большинстве учебных задач — Random.Shared. Свой new Random() — когда нужен свой seed для воспроизводимости.

4. Seed и воспроизводимость

var rnd1 = new Random(42); var rnd2 = new Random(42); Console.WriteLine(rnd1.Next(100)); // например, 66 Console.WriteLine(rnd2.Next(100)); // тоже 66 — та же последовательность

Применение:

  • Тестыфиксируем seed, получаем стабильный результат
  • Отладкавоспроизводим баг «иногда падает»
  • Демоодинаковый пример на каждом запуске
Важно: два Random с одинаковым seed дадут одинаковую последовательность; с разным — разную. new Random() без параметра — seed из системного времени/энтропии.

5. Дробные числа и диапазоны

NextDouble() даёт [0.0, 1.0). Чтобы получить число в произвольном диапазоне:

double min = 1.5, max = 3.5; double x = min + Random.Shared.NextDouble() * (max - min); // [1.5, 3.5)

Округление до нужного количества знаков:

double rounded = Math.Round(x, 2);

Для decimal (например, деньги):

decimal price = Math.Round((decimal)(Random.Shared.NextDouble() * 1000), 2);
Связать с темой 2: double для измерений, decimal для денег; и с темой 8 — форматирование F2.

6. Случайный элемент коллекции

string[] names = { "Анна", "Иван", "Ольга", "Пётр" }; string pick = names[Random.Shared.Next(names.Length)];

Для List<T> — то же через Count:

var list = new List<int> { 10, 20, 30, 40 }; int item = list[Random.Shared.Next(list.Count)];
Подчеркнуть: Next(collection.Length) / Next(collection.Count) — верхняя граница не включается, поэтому берём длину «как есть» (индексы 0…Length-1). Это удобно и безопасно.

7. Перемешивание (shuffle)

Классический алгоритм Фишера–Йетса:

static void Shuffle<T>(T[] array) { for (int i = array.Length - 1; i > 0; i--) { int j = Random.Shared.Next(i + 1); (array[i], array[j]) = (array[j], array[i]); // обмен через кортеж } }
Почему так, а не «Random.Shared.Next для каждого элемента и сортировка»: наивный вариант даёт смещённое распределение. Алгоритм Фишера–Йетса — равномерный. На занятии достаточно показать сам код и объяснить идею «идём с конца, меняем с случайным из начала».

(a, b) = (b, a) — обмен через кортеж (C# 7+); если ещё не проходили — обычная временная переменная.

8. Практические сценарии

  • КубикRandom.Shared.Next(1, 7).
  • МонеткаRandom.Shared.Next(2) == 0 ? "орёл" : "решка".

Случайный пароль из набора символов:

const string chars = "ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnpqrstuvwxyz23456789"; var sb = new StringBuilder(); for (int i = 0; i < 8; i++) sb.Append(chars[Random.Shared.Next(chars.Length)]); string password = sb.ToString();

Здесь сразу связываются темы 6 (массив/индекс), 8 (StringBuilder) и 10 — хороший «сквозной» пример.

  • Тестслучайный порядок вопросов в тесте — shuffle массива вопросов.
  • Массивзаполнение массива случайными числами — цикл + Next(min, max) (задача из темы 6).

9. Типичные ошибки и вопросы новичков

new Random() внутри цикла — самая частая и коварная ошибка:

for (int i = 0; i < 5; i++) { var r = new Random(); // плохо! Console.WriteLine(r.Next(100)); // часто одинаковые числа }

Причина: seed берётся из времени, а вызовы идут слишком быстро — seed совпадает. Правильно: создать Random один раз до цикла или использовать Random.Shared.

  • Верхняя границане включается — Next(1, 6) даёт 1…5, а не 1…6.
  • Next() без параметровогромный диапазон 0..int.MaxValue-1; почти никогда не нужен.
  • «Настоящая случайность»ожидание «настоящей случайности» — это псевдослучайные числа; для криптографии — RandomNumberGenerator.
  • МногопоточностьRandom и многопоточность — экземпляр Random не потокобезопасен; использовать Random.Shared или блокировки.
  • decimal напрямуюRandom для decimal напрямую — нет метода; конвертировать из NextDouble().
  • Наивное перемешиваниеперемешивание «наивным» способом — смещённое распределение; нужен Фишер–Йетс.
  • Индекс за границейслучайный индекс за границей — Next(arr.Length) правильно, Next(arr.Length + 1) — потенциальный выход за границы.
  • Тестысравнение «случайных» результатов в тестах — тест может «мигать»; фиксировать seed.

10. Практические задания

  • 1«Кубик»: бросить 100 раз, посчитать частоту каждого значения 1–6, вывести таблицу.
  • 2«Угадай число»: программа загадывает 1–100, пользователь угадывает, подсказки «больше/меньше», счётчик попыток (связать с темой 5).
  • 3Заполнить массив из 10 элементов случайными числами от −50 до 50, найти min/max/сумму (связать с темой 6).
  • 4Случайный выбор элемента из массива имён; вывести «сегодня дежурит: …».
  • 5Сгенерировать случайный пароль длины 8 из заданного набора символов (темы 6, 8, 10).
  • 6Перемешать массив вопросов теста (Фишер–Йетс) и вывести первые 3.
  • 7Сгенерировать decimal-цену от 100 до 1000 с двумя знаками после запятой; вывести с {price:F2}.
  • 8Показать воспроизводимость: два Random с seed 42 выдают одинаковую последовательность; с 43 — разную.
