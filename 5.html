Консультация 5. Циклы

for, while, do-while, foreach, break/continue, вложенные циклы и выбор подходящего цикла

Цели консультации

К концу занятия слушатель должен:

  • Пониматьзачем нужны циклы и как они меняют поток управления
  • Уметьуверенно пользоваться for, while, do-while, foreach
  • Пониматьразницу между циклами с предусловием и постусловием
  • Уметьприменять break и continue осознанно
  • Уметьписать вложенные циклы и выбирать подходящий цикл под задачу
  • Видетьтипичные ошибки: бесконечный цикл, выход за границы массива, «на единицу»

1. Зачем нужны циклы

Цикл позволяет повторить блок кода несколько раз без дублирования. Вместо:

Console.WriteLine(1); Console.WriteLine(2); Console.WriteLine(3);

пишем:

for (int i = 1; i <= 3; i++) { Console.WriteLine(i); }

Любой цикл состоит из трёх элементов:

  • Инициализацияначальное состояние
  • Условиепродолжения (проверяется перед каждой итерацией)
  • Изменениесостояния (шаг)

Понимание этих трёх частей — ключ к тому, чтобы не писать бесконечные циклы.

2. Цикл for

Самый частый цикл, когда известно количество итераций или нужен счётчик:

for (int i = 0; i < 5; i++) { Console.WriteLine($"Итерация {i}"); }

Разбор частей: int i = 0 — инициализация (один раз); i < 5 — условие (перед каждой итерацией); i++ — шаг (после каждой итерации). Тело выполняется, пока условие true.

Варианты:

  • Обратный отсчётfor (int i = 5; i > 0; i--);
  • Шаг больше 1for (int i = 0; i < 10; i += 2);
  • Несколько переменныхfor (int i = 0, j = 10; i < j; i++, j--);
  • Бесконечныйfor (;;) { ... } — с явным break внутри (см. раздел 5)
Важно: переменная i существует только внутри цикла (область видимости — тело цикла). Это защищает от случайного использования счётчика после выхода.
Типичная ловушка — «на единицу»: i <= arr.Length вместо i < arr.Length даёт выход за границы. Проговорить на конкретном примере.

3. Цикл while (с предусловием)

Используется, когда количество итераций заранее неизвестно, но есть условие продолжения:

int n = 1; while (n <= 5) { Console.WriteLine(n); n++; }

Особенности:

  • Условиепроверяется до тела — если оно сразу false, тело не выполнится ни разу
  • Инициализациядо цикла, изменение — внутри тела (легко забыть → бесконечный цикл)
  • Вводудобен для чтения ввода до корректного значения
int age; while (true) { Console.Write("Введите возраст: "); if (int.TryParse(Console.ReadLine(), out age) && age > 0) break; Console.WriteLine("Некорректно, попробуйте ещё раз"); }

Этот паттерн «цикл + break по успеху» стоит показать — он очень практичен.

4. Цикл do-while (с постусловием)

Тело выполняется хотя бы один раз, условие проверяется после тела:

int n; do { Console.Write("Введите положительное число: "); } while (!int.TryParse(Console.ReadLine(), out n) || n <= 0);

Когда уместен: когда действие нужно выполнить минимум один раз (запрос ввода, повтор меню, «сыграть ещё раз?»).

Сравнение с while — обязательный пункт занятия:

  • while«пока условие истинно, делай» (может не выполниться)
  • do-while«делай, пока условие истинно» (выполнится минимум раз)

5. break и continue

break — немедленный выход из ближайшего цикла (или switch):

for (int i = 0; i < 100; i++) { if (i == 5) break; // выходим из цикла при i == 5 Console.WriteLine(i); }

continue — пропуск остатка текущей итерации и переход к следующей:

for (int i = 0; i < 10; i++) { if (i % 2 == 0) continue; // пропускаем чётные Console.WriteLine(i); }

Правила хорошего тона:

  • break/continueне «запрещённый приём», но злоупотребление ими ухудшает читаемость
  • if вместо continueесли continue можно заменить обычным if без потери ясности — лучше if
  • Вложенностьbreak внутри вложенных циклов выходит только из внутреннего — важный момент (см. раздел 6)

6. Вложенные циклы

Цикл внутри цикла. Внешний отвечает за «строки», внутренний — за «столбцы»:

for (int i = 1; i <= 3; i++) { for (int j = 1; j <= 3; j++) { Console.Write($"{i * j,4}"); } Console.WriteLine(); }

Ключевые моменты:

  • Полный проходвнутренний цикл выполняется полностью на каждой итерации внешнего
  • Итерацииобщее число итераций внутреннего тела = произведение количеств итераций (3 × 3 = 9)
  • breakво внутреннем цикле выходит только из него, внешний продолжается. Если нужен выход из обоих — используют флаг, goto (не рекомендуем) или вынесение в метод с return

Пример с флагом:

bool found = false; for (int i = 0; i < n && !found; i++) { for (int j = 0; j < m; j++) { if (matrix[i, j] == target) { found = true; break; // выходим из внутреннего } } }

7. Цикл foreach

Специальный цикл для перебора элементов коллекции (массива, списка, строки):

int[] numbers = { 10, 20, 30 }; foreach (int n in numbers) { Console.WriteLine(n); }

Особенности:

  • Индексыне нужно думать об индексах и границах — идеален, когда нужны все элементы по порядку
  • Копияпеременная цикла — копия элемента; менять её бессмысленно (n = 0 не изменит массив)
  • Изменение коллекциинельзя изменить коллекцию во время перебора (добавить/удалить элемент) — будет исключение
  • Индексесли нужен индекс или нужно пропускать элементы — берите for

Сравнение for и foreach — обязательный пункт:

  • forкогда нужен индекс, обратный порядок, шаг, изменение элементов по индексу
  • foreachкогда нужен просто перебор «всех по порядку», читается короче и безопаснее

8. Как выбрать цикл

Короткое правило для слушателей:

  • forизвестно число итераций / нужен счётчик
  • whileнеизвестно, но есть условие
  • do-whileнужно выполнить минимум один раз
  • foreachперебрать коллекцию целиком
Часто один и тот же алгоритм можно записать разными циклами — цель занятия: понимать, что выбираем, и уметь переписать один в другой (полезное упражнение).

9. Практические задания

  • 1Вывести числа от 1 до 10 через for, затем от 10 до 1, затем только чётные.
  • 2Посчитать сумму чисел от 1 до N (N вводит пользователь) — через for и через while, сравнить.
  • 3Таблица умножения 1–9 через вложенные циклы с выравниванием ({x,4}).
  • 4Запрашивать у пользователя числа, пока не введён 0; посчитать сумму и количество (цикл + break).
  • 5«Угадай число»: программа загадывает число, пользователь вводит, программа подсказывает «больше/меньше», пока не угадано; посчитать число попыток (do-while или while (true)).
  • 6Найти первое число от 1 до 100, которое делится на 7 и на 9 одновременно (for + break).
  • 7Перебрать массив строк через foreach и вывести только те, что длиннее 3 символов (continue или if).
  • 8Вывести «ёлочку» из * высотой N через вложенные циклы.

10. Типичные ошибки и вопросы новичков

  • Бесконечный циклзабыли изменить счётчик (i++), неверное условие, while (true) без break.
  • «На единицу»i <= arr.Length → выход за границы; i < arr.Length — правильно.
  • Изменение коллекциив foreach — исключение InvalidOperationException.
  • Изменение через foreachпопытка изменить элемент через переменную foreach — не влияет на коллекцию.
  • break во вложенномвыходит только из внутреннего; новички ждут выхода из обоих.
  • continue в do-whileне пропускает проверку условия (в отличие от while); редкий, но коварный случай.
  • while и do-whileпутаница — «а если условие сразу ложно?».
  • Счётчик вне циклано используется после — область видимости и неинициализированные переменные.
  • for с doublefor (double d = 0; d != 1; d += 0.1) может не завершиться; для счётчиков — целые.
  • Глубокая вложенность3+ уровня циклов плохо читаются, стоит выносить во вспомогательные методы.

11. Итоги и что дальше

Вывод: освоили четыре вида циклов, научились выбирать подходящий, применять break/continue, писать вложенные циклы и перебирать коллекции через foreach. Главные навыки — не допускать бесконечных циклов и «на единицу».
