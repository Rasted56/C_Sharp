Консультация 2. Переменные, типы данных и преобразования

Значимые и ссылочные типы, объявление переменных, var, явные и неявные преобразования, Convert и TryParse

Цели консультации

К концу занятия слушатель должен:

  • Пониматьчто такое переменная и зачем нужны типы
  • Знатьосновные значимые и ссылочные типы C# и их различия
  • Уметьобъявлять переменные, присваивать значения, использовать var
  • Пониматьявное и неявное преобразование типов, уметь пользоваться Convert и Parse
  • Знатьчто такое константы, и когда их использовать

1. Что такое переменная и тип

Переменная — именованная область памяти, в которой хранится значение определённого типа. Тип определяет:

  • Значениякакие значения можно хранить
  • Памятьсколько памяти занимает значение
  • Операциикакие операции допустимы

В C# тип указывается при объявлении и (в большинстве случаев) не меняется:

int age = 25; string name = "Анна";

Правила именования: буквы, цифры, _, не начинается с цифры; рекомендуется camelCase для локальных переменных и PascalCase для типов и методов; имена осмысленные (userCount, а не x).

2. Значимые и ссылочные типы

Ключевое различие:

  • Значимыеvalue types — хранят само значение «на месте». При присваивании значение копируется. Примеры: int, double, bool, char, decimal, struct, enum.
  • Ссылочныеreference types — хранят ссылку на объект в куче. При присваивании копируется ссылка, а не объект. Примеры: string, массивы, классы, object.

Демонстрация на занятии:

int a = 5; int b = a; // копия значения b = 10; Console.WriteLine(a); // 5 — a не изменилось
Отдельно про string: это ссылочный тип, но он неизменяемый (immutable) — операции создают новую строку. Это часто удивляет новичков, стоит показать на примере.

3. Основные типы данных

Целые числа

  • byte0…255 — 1 байт
  • short−32 768…32 767 — 2 байта
  • int≈ ±2,1 млрд — 4 байта
  • long≈ ±9,2·10¹⁸ — 8 байт

int — тип по умолчанию для целых литералов. Суффикс L — для long (long x = 10L;).

Числа с плавающей точкой

  • float(суффикс f) — ~7 значащих цифр
  • double~15–17 значащих цифр, тип по умолчанию для дробных литералов
  • decimal(суффикс m) — точные десятичные вычисления, используется для денег
Важно проговорить: double/float хранят приближение, поэтому 0.1 + 0.2 != 0.3 в общем случае. Для финансов — только decimal.

Остальные

  • booltrue/false, без приведения к числу (в отличие от C/C++)
  • charодин символ в одинарных кавычках: 'A', '5', '\n'
  • stringпоследовательность символов в двойных кавычках; null допустим
object — базовый для всех типов var — не тип, а вывод типа компилятором dynamic — на базовом уровне не нужен int? — nullable-типы

4. Объявление и инициализация

int count; // объявление без значения count = 10; // присваивание int total = 100; // объявление с инициализацией int x = 1, y = 2; // несколько переменных одного типа const double Pi = 3.14; // константа — значение задаётся при объявлении и в дальнейшем не изменяется
Локальные переменные обязаны быть инициализированы до использования — компилятор это проверяет (в отличие от полей класса, которые получают значение по умолчанию).

var — не «любой тип», а вывод типа компилятором по правой части:

var n = 5; // int var s = "текст"; // string var d = 3.14; // double // var v; // ошибка: тип нельзя вывести

var полезен при длинных типах, но злоупотреблять им не стоит там, где тип неочевиден из правой части.

5. Преобразования типов

Неявное (implicit)

Безопасное, без потери данных, выполняется автоматически:

int i = 10; long l = i; // int → long, ок double d = i; // int → double, ок

Явное (explicit, приведение)

Может привести к потере данных, требует указания типа в скобках:

double d = 9.99; int i = (int)d; // 9 — дробная часть отбрасывается
Важно: при переполнении (например, (byte)300) результат «заворачивается» — стоит упомянуть, что есть checked/unchecked, но на базовом уровне достаточно знать о риске.

Преобразование строк

string s = "123"; int a = int.Parse(s); // бросает исключение, если строка не число bool ok = int.TryParse(s, out int b); // безопасный вариант: ok = true, b = 123

Convert

Универсальный класс для преобразований между базовыми типами:

int n = Convert.ToInt32("42"); double d = Convert.ToDouble("3.5"); string s = Convert.ToString(100);

Отличия, которые стоит проговорить:

  • Convert / TryParseдля строк и конкретного типа
  • Convertудобен при работе с object, null (например, Convert.ToInt32(null) вернёт 0, а int.Parse(null) бросит исключение)
  • TryParseпредпочтителен, когда данные приходят извне (ввод пользователя, файл)
Приведение ссылочных типов (as, is) — только упомянуть, подробно на теме ООП.

6. Работа с вводом пользователя

Практически важный сценарий:

Console.Write("Введите возраст: "); string input = Console.ReadLine(); if (int.TryParse(input, out int age)) Console.WriteLine($"Вам {age} лет"); else Console.WriteLine("Это не число");

Здесь сразу связываются темы: string, TryParse, if, интерполяция строк.

8. Типичные ошибки и вопросы новичков

  • Parse("abc")падает — учимся использовать TryParse или try/catch (последнее — на будущей теме).
  • = и ==путаница — присваивание vs сравнение.
  • 5 / 2деление целых даёт 2, а не 2.5; нужно 5.0 / 2 или приведение.
  • double для денегобъяснить, почему это плохо, и показать decimal.
  • varэто не «динамический тип» — частая ошибка понимания.
  • char vs stringодинарные vs двойные кавычки.
  • Неинициализированнаялокальная переменная — ошибка компиляции, а не null/0.
  • Культураразделитель дробной части — double.Parse("3.5") может вести себя по-разному в разных локалях; упомянуть CultureInfo.InvariantCulture.
