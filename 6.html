Консультация 6. Массивы и базовая работа с коллекциями

Массивы, многомерные и зубчатые массивы, методы Array, List<T> и Dictionary<TKey,TValue>

Цели консультации

К концу занятия слушатель должен:

  • Пониматьчто такое массив, как он хранится в памяти и почему индексация с нуля
  • Уметьсоздавать, инициализировать и перебирать одномерные и многомерные массивы
  • Знатьосновные свойства и методы массивов (Length, Rank, Array.Sort, Array.Reverse, Array.IndexOf)
  • Пониматьограничения массивов (фиксированный размер)
  • Уметьпользоваться List<T> для динамических списков и Dictionary<TKey,TValue> для пар «ключ-значение»
  • Выбиратьосознанно между массивом, списком и словарём

1. Что такое массив

Массив — набор элементов одного типа, расположенных в памяти непрерывно и доступных по индексу. Это ссылочный тип (тема 2): переменная хранит ссылку на объект в куче.

Ключевые свойства:

  • Фиксированная длиназадаётся при создании и не меняется
  • Индексация с нуляпервый элемент [0], последний [Length - 1]
  • Однородностьвсе элементы одного типа
  • Быстрый доступпо индексу — O(1), потому что адрес вычисляется арифметически
Почему с нуля — коротко: индекс — это смещение от начала, первый элемент на нулевом смещении. Не углубляться, но проговорить, чтобы не было «магии».

2. Создание и инициализация

Способы:

int[] a = new int[5]; // 5 элементов, все 0 int[] b = new int[] { 1, 2, 3 }; // явная инициализация int[] c = { 10, 20, 30 }; // краткая форма string[] names = new string[3]; // все элементы null var d = new[] { 1, 2, 3 }; // вывод типа → int[]
Важно: при new int[5] элементы получают значение по умолчанию типа (0 для чисел, false для bool, null для ссылочных). Это отличается от локальных переменных, которые обязаны быть инициализированы.

Длина — свойство Length:

Console.WriteLine(c.Length); // 3 Console.WriteLine(c[^1]); // 30 — индекс с конца (C# 8+) Console.WriteLine(c[^2]); // 20

^1 — «последний», ^2 — «предпоследний». Удобно, стоит показать.

3. Доступ и изменение элементов

int[] numbers = { 5, 10, 15 }; numbers[0] = 100; // изменение Console.WriteLine(numbers[0]); // 100
Главная ловушка — выход за границы:
Console.WriteLine(numbers[3]); // IndexOutOfRangeException

Это исключение времени выполнения, компилятор его не поймает. Правило: последний допустимый индекс — Length - 1. Связываем с темой 5 («на единицу» в цикле for).

4. Перебор массива

Через for — когда нужен индекс:

for (int i = 0; i < numbers.Length; i++) { Console.WriteLine($"[{i}] = {numbers[i]}"); }

Через foreach — когда нужны просто значения:

foreach (int n in numbers) { Console.WriteLine(n); }
Напоминаем из темы 5: foreach не даёт менять элементы (переменная — копия), для изменения — только for по индексу. И нельзя менять длину массива — её и нет.

5. Многомерные массивы

Двумерный прямоугольный массив — таблица:

int[,] matrix = new int[3, 4]; // 3 строки, 4 столбца matrix[0, 0] = 1; matrix[2, 3] = 9; Console.WriteLine(matrix.GetLength(0)); // 3 — строки Console.WriteLine(matrix.GetLength(1)); // 4 — столбцы Console.WriteLine(matrix.Length); // 12 — всего элементов Console.WriteLine(matrix.Rank); // 2 — размерность

Перебор — вложенные циклы:

for (int i = 0; i < matrix.GetLength(0); i++) { for (int j = 0; j < matrix.GetLength(1); j++) { Console.Write($"{matrix[i, j],4}"); } Console.WriteLine(); }
Важно: для многомерного массива Length — общее число элементов, а не длина «строки». Длины измерений — через GetLength(измерение). Это частая ошибка.

Инициализация:

int[,] grid = { { 1, 2, 3 }, { 4, 5, 6 } };

Зубчатый массив (jagged) — массив массивов, строки могут быть разной длины:

int[][] jagged = new int[3][]; jagged[0] = new int[] { 1, 2 }; jagged[1] = new int[] { 3, 4, 5 }; jagged[2] = new int[] { 6 }; foreach (var row in jagged) { foreach (int x in row) Console.Write($"{x} "); Console.WriteLine(); }
Разница, которую стоит проговорить: int[,] — прямоугольник, int[][] — «массив строк разной длины». Для таблиц — [,], для «списка списков» — [][].

6. Полезные методы класса Array

int[] data = { 3, 1, 4, 1, 5, 9, 2 }; Array.Sort(data); // сортировка по возрастанию: 1,1,2,3,4,5,9 Array.Reverse(data); // разворот: 9,5,4,3,2,1,1 int idx = Array.IndexOf(data, 4); // индекс первого вхождения 4 (или -1) Array.Clear(data, 0, data.Length); // обнулить все элементы int[] copy = (int[])data.Clone(); // поверхностная копия
Подчеркнуть: Sort и Reverse меняют исходный массив (не возвращают новый). Это важно, чтобы не удивляться.

Также: Array.Copy, Array.Resize (создаёт новый массив — имя обманчиво), Array.Exists, Array.Find. На базовом уровне — обзорно, чтобы знали, что есть.

7. Ограничения массивов

Массивы хороши для фиксированных наборов, но:

  • Размернельзя изменить — только создать новый и скопировать
  • Вставка/удалениев середину — дорого (сдвиг элементов)
  • Поисклинейный (если не отсортирован)

Когда этих ограничений достаточно — массив идеален (быстрый, компактный). Когда нужно добавлять/удалять — берём List<T>.

8. List<T> — динамический список

List<T> — обобщённая коллекция из System.Collections.Generic, которая сама растёт при добавлении:

using System.Collections.Generic; var list = new List<int> { 10, 20, 30 }; list.Add(40); // добавить в конец list.AddRange(new[] { 50, 60 }); list.Insert(0, 5); // вставить в начало list.Remove(20); // удалить первое вхождение list.RemoveAt(0); // удалить по индексу Console.WriteLine(list.Count); // количество (не Length!) Console.WriteLine(list[0]); // доступ по индексу

Ключевые отличия от массива:

  • Countа не Length
  • Размерменяется автоматически
  • МетодыAdd/Remove/Insert/Contains/IndexOf — удобные методы
  • Переборfor и foreach так же
  • Внутритот же массив, который пересоздаётся при росте (поэтому Capacity — полезно знать, но не обязательно)
Практически: в большинстве прикладных задач List<T> удобнее массива. Массив — когда размер известен заранее и важна производительность/компактность.

9. Dictionary<TKey, TValue> — словарь

Коллекция пар «ключ → значение» с быстрым поиском по ключу (O(1) в среднем):

var ages = new Dictionary<string, int> { ["Анна"] = 25, ["Иван"] = 30 }; ages["Ольга"] = 28; // добавление Console.WriteLine(ages["Анна"]); // 25 Console.WriteLine(ages.ContainsKey("Иван")); // true if (ages.TryGetValue("Пётр", out int age)) Console.WriteLine(age); else Console.WriteLine("Нет такого ключа");

Важные моменты:

  • Ключиуникальны — повторное ages["Анна"] = 26 перезапишет значение, а Add с существующим ключом бросит исключение
  • [] для отсутствующегоключ — исключение KeyNotFoundException, поэтому TryGetValue предпочтителен
  • Переборforeach (var pair in ages) с pair.Key/pair.Value; порядок не гарантирован
  • МетодыRemove, Count, Keys, Values — по аналогии
Когда использовать: подсчёты, справочники, «сопоставление id → объект», кэши.

10. Как выбрать коллекцию

Короткое правило:

  • Массив T[]фиксированный набор, важен индекс, размер известен
  • List<T>нужно добавлять/удалять, размер заранее неизвестен
  • Dictionary<TKey,TValue>нужен быстрый поиск по ключу
  • T[,]таблица
  • T[][]строки разной длины
Проговорить, что на старте достаточно List<T> и Dictionary<TKey,TValue> — этого хватает для 90% задач; остальные коллекции (HashSet, Queue, Stack, LinkedList) — позже.

12. Типичные ошибки и вопросы новичков

  • IndexOutOfRangeExceptioni <= Length вместо i < Length.
  • Length vs Countмассив → Length, List<T> → Count.
  • Многомерный массивLength даёт общее число, а не длину строки; нужен GetLength(i).
  • Array.Resize«не ресайзит» — создаёт новый массив; старая ссылка, если была, остаётся на старый.
  • Sort/Reverseменяют исходный массив — ожидание «вернёт новый» неверно.
  • ages["нет_ключа"]исключение; нужен TryGetValue/ContainsKey.
  • Изменение спискав foreach — исключение; для удаления — for с конца или RemoveAll.
  • List<T> vs T[]путаница Length/Count, а также неявное ожидание, что массив «сам вырастет».
  • null-элементыв массиве строк — обращение к .Length у null даёт NullReferenceException; проверять.
  • Копирование через =копируется ссылка, а не массив (тема 2); для копии — Clone/Array.Copy/ToList().
  • Порядок в Dictionaryне гарантирован; не полагаться на него.
