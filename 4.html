Консультация 4. Условные конструкции и ветвление

if / else if / else, вложенные условия, switch, switch-выражение и pattern matching

Цели консультации

К концу занятия слушатель должен:

  • Пониматьзачем нужно ветвление и как работает поток управления
  • Уметьуверенно писать if, else if, else, в том числе вложенные
  • Знатькогда уместен switch и чем он отличается от цепочки if
  • Уметьпользоваться switch-выражением (C# 8+) и pattern matching
  • Видетьтипичные ошибки: «висячий else», забытый break, сравнение через =, порядок условий

1. Зачем нужно ветвление

Программа по умолчанию выполняется линейно — сверху вниз. Ветвление позволяет выбрать, какой блок кода выполнить, в зависимости от условия. Условие — это выражение типа bool (true/false). В C# нет неявного приведения чисел к bool (в отличие от C/C++): if (1) — ошибка компиляции, нужно if (x != 0).

Ключевая мысль: любое ветвление — это «развилка», и важно, чтобы все возможные случаи были осознанно обработаны (или осознанно оставлены без обработки).

2. Конструкция if

Простейшая форма:

if (условие) { // выполняется, если условие true }

Пример:

int age = 20; if (age >= 18) { Console.WriteLine("Доступ разрешён"); }

Правила:

  • Условиеобязательно типа bool
  • Телоблок в {}; если инструкция одна, скобки формально можно опустить, но на обучении рекомендуем всегда ставить {} — это защищает от ошибок при доработке
  • Отступыобязательны для читаемости

3. if / else

if (age >= 18) { Console.WriteLine("Взрослый"); } else { Console.WriteLine("Несовершеннолетний"); }

else выполняется, когда условие ложно. else не имеет собственного условия — он «прилипает» к ближайшему if.

«Висячий else» — классическая ловушка:
if (a > 0) if (b > 0) Console.WriteLine("оба положительны"); else Console.WriteLine("b не положительно"); // относится ко внутреннему if!

Скобки снимают неоднозначность — ещё один аргумент всегда их ставить.

4. else if — цепочка условий

Когда вариантов больше двух:

int score = 75; if (score >= 90) { Console.WriteLine("Отлично"); } else if (score >= 75) { Console.WriteLine("Хорошо"); } else if (score >= 60) { Console.WriteLine("Удовлетворительно"); } else { Console.WriteLine("Не сдано"); }
Критически важное правило: условия проверяются сверху вниз, и выполняется только первая подходящая ветвь. Поэтому порядок имеет значение: если поменять местами >= 60 и >= 75, ветка «Хорошо» станет недостижимой для значений 75–89 (они попадут в >= 60). Это стоит показать на конкретном примере — типичная ошибка новичков.

Альтернатива — независимые if (каждый проверяется отдельно). Разница:

  • else ifвзаимоисключающие варианты («одно из»)
  • отдельные ifнезависимые проверки («каждое само по себе»)

Учить различать эти два сценария — важная часть занятия.

5. Вложенные условия

if (user != null) { if (user.IsActive) { Console.WriteLine("Добро пожаловать"); } else { Console.WriteLine("Аккаунт заблокирован"); } } else { Console.WriteLine("Пользователь не найден"); }
Вложенность глубже 2–3 уровней — сигнал, что стоит подумать о рефакторинге (ранний выход, объединение условий, выделение метода). Проговорить это сразу, чтобы не приучать к «лесенкам».

Ранний выход (guard clauses):

if (user == null) { Console.WriteLine("Не найден"); return; } if (!user.IsActive) { Console.WriteLine("Заблокирован"); return; } Console.WriteLine("Добро пожаловать");

Показываем как более читаемую альтернативу вложенности.

6. Логические связки в условиях

Условия можно комбинировать через &&, ||, ! (тема 3). Примеры:

if (age >= 18 && hasTicket) { ... } if (role == "admin" || role == "moderator") { ... } if (!isBlocked) { ... }

Напоминаем про короткое замыкание и про то, что сложные условия лучше разбивать на именованные переменные:

bool isAdult = age >= 18; bool canEnter = isAdult && hasTicket; if (canEnter) { ... }

7. Конструкция switch

Когда проверяется одно выражение на набор конкретных значений, switch читается лучше цепочки if:

int day = 3; switch (day) { case 1: Console.WriteLine("Понедельник"); break; case 2: Console.WriteLine("Вторник"); break; case 3: Console.WriteLine("Среда"); break; default: Console.WriteLine("Другой день"); break; }

Ключевые правила C#:

  • caseконстантные значения, совместимые по типу с выражением switch
  • breakобязателен в конце непустой ветви (в C# нет «проваливания» по умолчанию, как в C)
  • defaultнеобязателен, но полезен как «страховка»

Несколько case подряд могут вести к одному блоку:

case 6: case 7: Console.WriteLine("Выходной"); break;

Это законно и часто используется. goto case существует, но на базовом уровне — не рекомендуем; упомянуть, что есть.

8. switch-выражение (C# 8+)

Современный и компактный вариант, возвращает значение:

string dayName = day switch { 1 => "Понедельник", 2 => "Вторник", 3 => "Среда", 6 or 7 => "Выходной", _ => "Другой день" };

Что важно:

  • _«любой другой случай» (discard, аналог default)
  • or, and, notлогические паттерны
  • Порядокветви взаимоисключающие, порядок проверки — сверху вниз
  • Исключениеесли ни одна ветвь не подошла и нет _ — исключение во время выполнения
Это стоит показать как «современный способ», но с оговоркой: на старте можно писать обычный switch, а switch-выражение — когда освоитесь.

9. Pattern matching — кратко

switch умеет работать не только с константами, но и с паттернами:

switch (obj) { case int n when n > 0: Console.WriteLine($"Положительное целое: {n}"); break; case string s: Console.WriteLine($"Строка длины {s.Length}"); break; case null: Console.WriteLine("null"); break; }
  • case int nпроверка типа + объявление переменной
  • whenдополнительное условие (guard)
  • case nullявная проверка на null
На базовом уровне — обзорно, чтобы слушатель узнал конструкцию и не пугался, встретив её в чужом коде. Подробно — на теме ООП.

10. Практические задания

  • 1Ввести число и вывести, положительное оно, отрицательное или ноль (if/else if/else).
  • 2Ввести оценку 1–5 и вывести текстовое описание через switch.
  • 3Ввести год и определить, високосный ли он (условие с &&/||, аккуратно с порядком).
  • 4Калькулятор: два числа и оператор (+, -, *, /), выбор действия через switch; обработать деление на ноль.
  • 5Переписать задачу 1 через switch-выражение с pattern matching (case > 0, case < 0, case 0 — подсказать синтаксис).
  • 6Определить время года по номеру месяца: сначала через if/else if, потом через switch с несколькими case; сравнить читаемость.
  • 7Найти и исправить ошибку в коде с «висячим else» (заранее подготовленный пример).

11. Типичные ошибки и вопросы новичков

  • = вместо ==в условии — if (x = 5).
  • Порядок условийв else if — недостижимые ветви из-за неправильной последовательности.
  • Забытый breakв switch — ошибка компиляции (в C# это плюс, но новичка пугает).
  • «Висячий else»без скобок относится не к тому if.
  • switch по диапазонупо неконстантным значениям — например, по диапазону; нужно if или pattern matching.
  • Пустой defaultотсутствие default — забыли обработать «всё остальное».
  • Регистр строксравнение строк без учёта регистра — "Admin" != "admin"; упомянуть StringComparison.OrdinalIgnoreCase.
  • Глубокая вложенностьслишком глубокая вложенность — не читается; показать ранний выход.
  • if (flag == true)избыточно, достаточно if (flag).
  • else if vs ifсмешение else if и независимых if — разный смысл, частая логическая ошибка.
